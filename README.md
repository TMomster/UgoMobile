# UGo Mobile（原型）

UGO 是一款安卓围棋软件，采用 **Rust + Capacitor** 架构：

- **Rust 围棋引擎**（`core-go/`）：`no_std` 编译为 `wasm32-unknown-unknown`，
  通过纯 C ABI 导出，前端直接读写 WASM 线性内存，无任何胶水代码生成步骤。
- **Web 前端**（`www/`）：Canvas 棋盘渲染 + 交互，功能菜单。
- **Capacitor Android 壳**（`android/`）：打包为原生 App。

## 原型功能

- 启动闪屏：UGO LOGO + 「UGo Mobile」标题，约 1.8 秒后淡出进入棋盘。
- 主界面即棋盘：点击交叉点落子（黑白轮流，即时生效），状态栏显示行棋方 / 手数 / 提子数；
  **手势在棋盘外的空白区域**：双击空白 = 虚着，双指同时按下 = 悔棋
  （棋盘内只负责落子，无单/双击歧义）。
- 点击**棋盘右缘的「菜单」按钮**呼出功能菜单，包括：
  - **棋盘边缘标号显示**：开 / 关（列 A–T 跳过 I，行号自下而上）；
  - **落子显示**：手数（每颗子上显示第几手）/ 圆圈标记（最后一手红圈）/ 关；
  - **棋盘路数**：9 / 13 / 19（切换即开新对局）；
  - **规则**：中国规则（数子 · 贴 7.5）/ 日本规则（数目 · 贴 6.5）/ 韩国规则（同日本）。
  - 另有：虚着（主界面与菜单均有按钮，双方连续虚着即终局估算得分）、认输、新对局。
- 引擎规则：气与提子、自杀禁着、简单劫（禁立即回提）、终局估算计分
  （死活由形势分析自动判定，可在终局前提净死子复核）。
- **结果弹窗显示形势明细**：终局 / 中盘认输均给出
  「终局（中盘胜），黑x目 提x目，白x目 提x目，X胜X.5目」。
- **分析模式**：摆放工具含 黑子 / 白子 / 交替 / **记号（红圈，点选切换）**；
  工具条提供 退5手 / 退1手 / 重置 / 下1手 / 下5手 导航按钮
  （前进基于引擎的重做机制 `ugo_redo`，可回放已悔掉的着法）。
- **人机对弈（AI 对手）**：菜单中开启「AI 执黑 / AI 执白」，
  可设置**机器强度（1–10）**与**行棋风格**（均衡 / 激进 / 稳健 / 取地 / 厚势），
  设置持久化到 `localStorage`。AI 自动应答、会虚着终局、
  大幅落后时中盘认输；悔棋自动连退两手回到自己行棋。
- **形势分析**：点击「形势」开关，棋盘实时叠加形势层——
  确定地以黑白圆点表示、势力/模样以半透明晕染表示、被判死的棋子
  上面标对方的领地点；底部出现**形势估算条**（双方点数 + 含贴目的
  领先目数 + 黑白占比条），随每手棋实时更新。

## 形势分析算法（泛洪辐射影响力）

`core-go/src/lib.rs` 的「形势分析」段，经典影响力模型的组合：

```
1. 棋块普查：气数 / 真眼数 / 是否接触敌子；
   一口气（且最后的眼填不掉）判死；两气无眼的接触块用
   attack/defend 深度受限吃子搜索确认（征子自动被读到）。
2. 泛洪辐射：每颗棋子以 BFS 向四周泛洪辐射影响力，
   贡献随曼哈顿距离衰减（RAY_W 表），被对方棋子阻挡、
   可穿过己方棋子；弱棋块辐射打折，死子按对方身份辐射。
   同一点上黑白贡献代数相加 → 相互抵消，得净影响力 R。
3. 形态学确认（Bouzy 式腐蚀）：|R| 达标的区域「平台化」后
   做 8 轮腐蚀（棋子与盘缘视为支撑）。被围出口袋保住
   「确定地」标签；孤子与朝开阔面宣称的地盘被腐蚀掉，
   只保留「势力/模样」标签。
4. 输出：净影响力 R（INFLU）、分类图 TERR（±2 确定地 /
   ±1 势力 / 0 中立）、形势估算 EST（按规则计点，不含贴目）。
```

- 分类守卫：紧贴活棋的空点不可能是对方的确定地（自动降级为势力）。
- 前端渲染分三层：确定地圆点 / 势力晕染 / 死子上的对方领地点。
- 终局双停计分也走同一套死活判定，替代原型的「全子存活」假设。

## AI 算法模型

引擎内置经典计算机围棋架构（`core-go/src/lib.rs` 的 AI 段）：

```
评估（点 ×8，含贴目）= 数子/数目地盘估算 + 模样潜力项
                      + 时序修正（叫吃 / 被追两气块 / 死子返还）
强制战术 = 己方叫吃（读子确认有救 → 只搜逃点/解围点）
         + 敌方叫吃（只搜提子点）——「被打吃不应」被机制性排除
候选生成 = 强制战术（被打吃必应：读子确认有救只搜逃点，否则弃子）
         + 战术急所（提子/救子/紧气，试下验证，权重压过布局分）
         + 开局形状指导（空角大场 / 小飞大飞守角 / 挂角 / 一间夹，
           相对几何规则，布局期按剩余量衰减）
         + 扩张潜力（辐射前沿空缺）+ 削减价值（对方势力内）
         + 布局线位修正
选点     = 根迭代加深（上轮最优优先，预算不足回退上一层）
         + alpha-beta 负极大 + 近平局决胜（战术着 2 点 / 普通着 0.5 点窗口）
```

- **评估**与「势力」显示共用同一泛洪辐射模型：确定地计 1 点、
  模样按风格权重折价；叶子处对两气无眼接触块做吃子读子，
  读死的块按对方计点，行棋方的启发死子返还部分损失——
  AI 不会浪费手数防守无望的棋，也不会放着能救的子不管。
- **虚着（pass）**：逐点检查落子的即时地盘增益，全盘无正增益
  （只剩填自己的地 / 无利可图）才虚着；对手虚着且己方
  领先则虚着终局；中后盘领先不足 25 目以上方认输。
- **强度 1–10**：控制搜索深度（1–5 层，高强度配合迭代加深）、
  每层候选宽度、根节点噪声（低强度像初学者）与读子深度
  （最高强度征子读 12 层）。
- **风格**：攻杀 / 防守 / 实地 / 外势 四个 0–100 权重，前端以
  五种预设呈现（均衡/激进/稳健/取地/厚势）。
- 引擎导出：`ugo_ai_config`（强度+权重）、`ugo_ai_set_seed`、
  `ugo_ai_genmove`（返回 0 停/1 落/2 认输，坐标读 `ugo_ai_x/ugo_ai_y`），
  搜索用独立的试下/撤销对（`try_play/untry_play`），不污染悔棋历史。
  势力分析导出：`ugo_analyze`、`ugo_influence_ptr`、`ugo_terr_ptr`、
  `ugo_est_black / ugo_est_white`。

### 参考的研究

- **辐射影响力模型**：Zobrist (1970) 的 influence function；
  GNU Go 文档「Influence and Territory」——棋子向四周辐射、
  距离衰减、异色相消的经典形式。
- **Bouzy (1995)** *Mathematical Morphology Applied to Computer Go*：
  膨胀-腐蚀判定势力与地域；本实现的「平台化 + 腐蚀」即取其形态学
  确认思想（GNU Go 的 5/21 参数版本见其文档第 14 章）。
- **战术读子**：GNU Go `reading.c` 的 attack/defend 深度受限
  吃子搜索（征子、扑、接不归自动覆盖）。
- **搜索**：经典 alpha-beta 剪枝（负极大形式），叶子全盘评估 +
  评估噪声模拟低强度棋手。
- 综述：Bouzy & Cazenave (2001) *Computer Go: An AI Oriented Survey*。

## 目录结构

```
UGoMobile/
├── core-go/            # Rust 围棋引擎（no_std → wasm32）
│   ├── Cargo.toml
│   └── src/lib.rs      # 规则 + 泛洪辐射势力分析 + alpha-beta AI
├── www/                # 前端（Capacitor webDir）
│   ├── index.html      # 闪屏 + 棋盘 + 势力估算条 + 菜单
│   ├── style.css
│   ├── app.js          # 渲染 / 交互 / WASM 加载 / AI 调度
│   ├── assets/logo.png
│   └── wasm/ugo_core.wasm
├── tools/
│   ├── ai-selftest.mjs     # Node AI 自测（规则/合法性/战术/势力图/终局/耗时）
│   └── tune-influence.mjs  # 势力图 ASCII 调参工具
├── android/            # Capacitor 生成的安卓工程
├── capacitor.config.json
└── UGO.png             # 原始 LOGO
```

## 开发与构建

### 引擎（Rust → WASM）

```bash
rustup target add wasm32-unknown-unknown
cd core-go
cargo build --release --target wasm32-unknown-unknown
cp target/wasm32-unknown-unknown/release/ugo_core.wasm ../www/wasm/
# 引擎有更新时，同步把 www/app.js 中 fetch 的 ?v=N 版本号加一，绕过 WebView 缓存
```

### 网页端调试

```bash
cd www
npx http-server -p 8642 -s -c-1     # -c-1 禁用缓存
# 浏览器打开 http://127.0.0.1:8642
```

### AI 自测（Node，无需浏览器）

```bash
node tools/ai-selftest.mjs
# 规则回归 / 各路数各强度合法性 / 自对弈自然终局 / 战术行为
# / 势力图（辐射·抵消·死子） / genmove 无副作用 / 耗时
node tools/tune-influence.mjs   # 势力图 ASCII 可视化（调参用）
```

### Android

```bash
npx cap sync android        # 把 www/ 同步进安卓工程
cd android
./gradlew assembleDebug     # 产物: android/app/build/outputs/apk/debug/app-debug.apk
```

## 已知限制（原型范围）

- 死活判定为启发式 + 深度受限读子（复杂死活、双活仍可能误判）；
- AI 为经典启发式架构（影响力评估 + 战术读子 + alpha-beta），
  强度上限约业余初级水平，不含蒙特卡洛 / 神经网络；
- 采用简单劫（中国规则严格来说为禁全同形/Positional Superko）;
- 无棋谱保存 / 对局计时；
- WASM 引擎与前端之间通过固定导出函数通信，引擎内存不会增长（无分配器）。
